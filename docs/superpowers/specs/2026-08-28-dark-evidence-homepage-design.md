## 1. 目标与优先级

本规格是已选方案一的实现附录。它覆盖上游规格中与首页视觉冲突的内容：首屏改为一个主按钮，首页采用深色证据引擎而非白色卡片舞台，用户提供的科技视觉素材可以作为装饰性本地资产。业务、安全、发布数据、滚动原生性、可访问性和生产边界仍由上游规格约束。

实现目标不是把整张方案图铺成背景，而是把方案中的排版、比例、色彩、素材焦点和章节节奏重建为语义化、响应式 HTML/CSS。桌面端以 1440px 参考视口达到高视觉一致性；窄桌面和手机端保持同一视觉语言但允许合理重排。

## 2. 锁定视觉参数

- 页面底色以 `#07090D`、`#0D1117` 和 `#12171F` 为主，文字使用 `#FFFFFF`、`#D7DDE5` 和 `#8E99A8`。
- 唯一品牌强调色为电光蓝 `#0F6FEF`；不得再使用青色、橙色或渐变制造第二强调体系。
- 最大内容宽度 `1280px`；桌面 gutter 为 `32px`，窄桌面 `24px`，手机 `20px`。
- 桌面首屏标题 `clamp(4.5rem, 6.3vw, 5.75rem)`，行高 `1.02`；手机标题 `clamp(2.625rem, 12vw, 3.5rem)`。
- 大章节上下留白为 `clamp(7.5rem, 11vw, 11.25rem)`；能力行不得压缩成普通小卡片矩阵。
- 常规圆角 `0—4px`，按钮最多 `4px`；阴影仅用于极轻的素材分层，章节边界使用 `1px` 细线。
- 导航、首屏、能力章节、应用场景、证据、动态和最终 CTA 必须形成同一深色系统。

## 3. 页面结构与五章映射

页面保持五个 `data-story-chapter`，以兼容原生滚动叙事和现有发布内容契约：

1. `story-purpose`：深色首屏和平台定位。主标题固定为“让 AI 转型，从可验证的业务价值开始”；说明为“评估准备度，匹配高价值场景，形成可执行的实施路径。”；首屏只显示一个主要按钮“开始 AI 就绪度评估”。
2. `story-assessment`：能力 01“评估企业准备度”，展示确定性评估说明；模拟输出就近显示“演示数据”。
3. `story-matching`：能力 02“匹配高价值场景”，消费已发布场景与行业数据，并包含应用场景入口。
4. `story-roadmap`：能力 03“设计可执行交付”，消费已发布服务数据，并形成横向工业场景大区块。
5. `story-evidence`：成果/案例、审核资源或当前公告、动态列表、最终行动区和页脚前收束。

章节进度仍为可聚焦的 `01—05` 锚点。页面不监听或阻止 `wheel`、触控板、滚动条、Page Down、Space、方向键和浏览器查找。

## 5. 数据与内容边界

- 行业、场景、服务、案例、资源和公告只消费 `content_repository.home_page_data()` 的已发布 view model。
- 不新增数据库查询、路由、schema 或生产 API，不修改 `catalog_content_repository.py`。
- 真实案例使用 `verification_label`；未获授权的客户名、Logo、引语、ROI、节省比例和使用规模不得出现。
- “12 周”“3 个优先场景”“阶段路径”等方案示例必须逐项紧邻显示“演示数据”。如果不展示这些示例，则不得用别的虚构数字代替。
- 首页“洞察与动态”使用当前公告和审核资源；缺少条目时显示诚实空状态，不伪造日期或新闻。

## 6. 导航、组件和行为

- 首页导航改为黑色紧凑导航；使用现有 Logo 和现有内部路由。首页隐藏顶部 `site-signal`，其他公共页面保持原样。
- 首页首屏只保留一个主要 CTA；场景、服务、案例和资源入口放在后续章节。
- 首页隐藏或改造现有底部悬浮 CTA，避免与最终 CTA 重复；其他页面不受影响。
- 图片 hover 只允许 `transform: scale(1.02)` 左右；章节进入只动画 `opacity` 和 `transform`，时长 500—800ms。
- `prefers-reduced-motion: reduce` 时取消粘性、吸附和过渡，所有内容完整可见。
- 无 JavaScript 时所有章节、链接、图片和行动仍处于普通文档流。

## 7. 响应式与可访问性

- 1440px：严格匹配选定方案的首屏比例、标题尺度、右侧主视觉、能力大行、证据数据和动态列表。
- 1024px/910px：标题和素材不重叠；右侧章节进度不得覆盖正文；允许从双栏改为比例较小的双栏或单栏。
- 390px 与 320px：单栏自然流，无横向溢出；固定进度改为横向章节条或静态列表；触控目标至少 44×44px。
- 保留一个 `h1`，标题层级连续，跳转锚点有 `scroll-margin-top`，焦点样式达到 WCAG 2.2 AA。

## 8. 验收门槛

1. 相同 1440px 视口下，选定方案与本地首页完成并排视觉比较；标题、主视觉、比例、色彩、留白、边框、圆角和章节节奏无 P0—P2 差异。
2. 1024px、910px、390px、320px 无页面级横向溢出、遮挡、重叠或不可达操作。
3. 首页导航、章节锚点、评估 CTA、场景/服务/案例/资源入口全部使用真实路由并可操作。
4. 所有模拟结果就近标记“演示数据”；不存在未标注的虚构指标。
5. Python 聚焦责任集、Node 运行时测试、语法检查、`git diff --check` 和本地 Browser 主流程均有新鲜通过证据。
6. `design-qa.md` 最终为 `final result: passed`，独立审查无未闭合 P0—P2。
7. 不运行本计划未授权的 full suite，不部署，不访问生产或真实外网。
